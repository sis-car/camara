# camara

## ¿Para qué sirve el agente de IA en este repositorio?

El agente es un asistente técnico que colabora con vos dentro del proyecto en GitHub.  
Su objetivo es ahorrarte tiempo, reducir errores y ayudarte a avanzar más rápido.

### ¿Cómo trabaja?

1. Lee el contexto del repositorio (archivos, estructura y cambios).
2. Entiende la tarea que le pedís (por ejemplo: corregir algo o mejorar una parte).
3. Propone y aplica cambios concretos.
4. Valida resultados (cuando hay tests o verificaciones disponibles).

### ¿Qué valor aporta?

- **Automatiza tareas repetitivas**: cambios pequeños en varios archivos, ajustes de formato, actualizaciones simples.
- **Ayuda a escribir código**: crea funciones, corrige errores y sugiere implementaciones.
- **Revisa Pull Requests**: detecta posibles problemas, inconsistencias o mejoras de calidad.
- **Sugiere mejoras**: claridad en código, estructura, documentación y mantenimiento general.

### Ejemplos básicos de uso

- “Explicame qué hace este archivo y cómo mejorarlo.”
- “Corregí este bug y dejá el cambio listo para PR.”
- “Revisá este PR y decime riesgos o mejoras.”
- “Automatizá esta tarea manual que hacemos siempre.”
